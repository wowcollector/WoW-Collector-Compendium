Nathria Weapon Tokens

It's no secret the weapon tokens that drop from many Nathria bosses are a bit of a headache to figure out:

  • They can only be used by certain classes.
  • Each covenant has a different set of transmogs to unlock
  • You need the right covenant x class combination to fully collect all they have to offer.

Thus, in an effort to reduce changing Covenants as much as possible, here's a nice lil' table with one of the more optimal class x covenant setups. This takes into account the various covenant-specific stuff you have to farm listed on the Covenant Farming page.

First though, a few more considerations:

  • The weapon tokens from LFR, Normal and Heroic Castle Nathria unlock the same appearance sources - only their item levels and the vendors they come from are different. Farm whichever difficulty you're missing most other appearances on!
  • The Mythic weapon tokens have a separate set of appearance sources.
  • There's a few different 'pools' of appearance sources depending on who drops the weapon token:
    • Pool 1: The big shiny spherule from non-Denathrius bosses.
    • Pool 2: The bead tokens from Artificer Xy'mon and Lady Inerva Darkvein.
    • Pool 3: The bead tokens from Stone Legion Generals.
    • Pool 4: The big shiny spherule from Denathrius himself.
  • The spherule types are always usable by the same class combinations:
    • Mystic: Hunter, Mage, Druid
    • Abominable: Death Knight, Warlock, Demon Hunter
    • Venerated: Paladin, Priest, Shaman
    • Zenith: Warrior, Rogue, Monk, Evoker
    • Apogee: Warrior, Paladin, Priest, Monk, Evoker
    • Thaumaturgic: Shaman, Mage, Warlock, Druid

You'll note there's some classes missing from the last two. This is because, for example, Rogues don't have a usable dagger they can buy with there two bead tokens.

The priority order with which this table was made:

  1. Classes best suited for collecting very specific things as noted in the Covenant Farming page linked above, while ensuring they're as spread out as possible based on their "big spherule token" configurations.
  2. Ensuring as much spread as possible for the smaller bead tokens (which will be 100%'d much faster than the rest, but still)

The only awkward inflection point is Priest. You really want a Cloth class on Venthyr for the Transport Network, but for the Venerated Spherule, it would be a better fit on Kyrian. With Priest on Venthyr, both it and Shaman basically count as a single character for the purpose of using up the Venerated Spherule optimally.

The empty slots is because we ran out of classes. It's fine. You don't need to have every class x covenant combination.

Lastly, remember to spread out your weapon tokens evenly between covenants. You want to slowly chip away at each covenant's appearances sources at the same time or, when close to the end, you may find yourself looting the occasional useless spherule.
